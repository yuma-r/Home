Details

This game is a simple 2D sandbox, where you can brake blocks and play with the items.
It runs on your desktop with a transparent background, where you can click through.
The game is inspiered by "Minecraft" and "Desctop budy".

Physics

The game uses the default unity physics engine with rigidbody2D.
